# Rock Paper Scissors Game

This is a simple Python-based Rock Paper Scissors game created to practice basic Python concepts such as user input, dictionaries, conditionals, and game logic.

## Concepts Practiced
- User input
- Dictionaries
- Random choice
- Conditional statements (`if`, `elif`, `else`)
- Basic game logic

## Game Rules
- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock

## Value Mapping Used
- Rock → `1`
- Paper → `-1`
- Scissors → `0`

## How It Works
- The computer randomly selects Rock, Paper, or Scissors
- The user enters their choice
- The program compares both choices
- It prints whether the result is a win, loss, or draw

## File
- `rock_paper_scissors.py` → contains the full game logic

## Learning Outcome
By building this game, I practiced how to:
- take input from the user
- map values using dictionaries
- use random selections in Python
- apply conditional logic to solve a simple game problem

This version keeps the game logic explicit using multiple conditional checks for clarity and practice.
